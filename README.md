# Khoza 42 

A personal portfolio website celebrating **Malibongwe Prince Khoza**, a professional footballer and model. The website brings together his football career, player profile, performance statistics, and modelling portfolio in one elegant digital space.

## About the Project

Khoza 42 is a modern, responsive website designed to showcase Malibongwe Khoza's professional journey both on and off the pitch. It combines a clean, classy aesthetic with football-inspired elements to create a distinctive personal brand.

## Features

- **Home:** An immersive hero section introducing Khoza 42.
- **Player Profile:** Personal details, position, and football career information.
- **Football Career:** Career milestones and achievements.
- **Statistics:** Player appearances, goals, assists, and other performance metrics.
- **Highlights:** Links to football highlight videos.
- **Modelling Portfolio:** A stylish showcase of his modelling profile and photographs.
- **Responsive Design:** Designed to provide a user-friendly experience across different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript (if applicable)
- Google Fonts — Montserrat and Playfair Display
- YouTube — for linked football highlights

## Design Concept

The website uses a sophisticated visual identity built around a **white, gold, and blue colour palette**, combining professional presentation with a modern football aesthetic. The design aims to balance athletic performance, personal style, and elegance.
